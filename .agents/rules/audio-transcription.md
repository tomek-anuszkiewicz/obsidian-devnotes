# Audio Transcription

When the user sends audio, begin the response with this block and preserve the spoken language:

> 🎙️ **Audio Transcription:**  
> *"Exact words spoken by the user in original language..."*

Do not put a greeting, explanation, tool update, or vault edit before the transcription.
