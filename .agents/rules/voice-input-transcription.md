# Voice Input Transcription

- Whenever the user provides an audio recording or voice message, transcribe the spoken words into text.
- Place the verbatim transcription at the very top of the response before any other text, reasoning, or action summary (for example, in a `> **Transkrypcja:** ...` or quote block).
- Then proceed with answering the query and executing requested actions based on the transcription.
