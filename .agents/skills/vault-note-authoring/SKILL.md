# Vault Note Authoring

Use this skill only after the user has explicitly asked to rewrite an existing public note.

Read [the faithful rewrite workflow](references/note-authoring-workflow.md) and the target note. Those are the only materials needed for this task; do not search for, read, link to, or edit other notes.

Run the relevant checks before handoff. Do not commit unless the user asks.
