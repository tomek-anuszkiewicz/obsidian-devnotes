# Vault Note Authoring

Use this skill only after the user has explicitly asked to rewrite an existing public note.

Read [Rewrite prompt.md](../../../Rewrite%20prompt.md) and the target note. Those are the only vault notes needed for this task; do not search for, read, link to, or edit other notes.

Keep the note's ideas, claims, examples, and structure unchanged unless a small structural change is necessary to make the existing text readable. Remove academic or AI-generated phrasing by replacing unnecessary abstraction with concrete, natural engineering language. Do not add concepts, jargon, evidence, links, summaries, or recommendations.

For each paragraph, check whether a senior engineer would say it naturally, whether a simpler wording keeps the same meaning, and whether it explains a mechanism instead of merely naming one. Run the relevant checks before handoff. Do not commit unless the user asks.
