# Vault Note Authoring

Use this skill only after the user has explicitly asked to write or substantially revise a public note.

1. Read [the workflow](references/note-authoring-workflow.md).
2. Find nearby notes and links only when they will help the reader or prevent duplicate material.
3. Write in English using `practitioner-voice`. Choose the structure, examples, and level of detail that fit the subject. Use the other vault skills when they clarify a real decision.
4. Keep the public/private boundary intact. Check changed public notes with the relevant scripts before handoff.

Do not force a fixed outline, summary, link count, or cross-note edit. Do not commit unless the user asks.
